# saya-sales-sync-privacy

SAYA の販売管理まわりの公開ページ置き場です（GitHub Pages）。

| パス | 内容 |
|---|---|
| `index.html` | SAYA Sales Sync（eBay 連携アプリ）のプライバシーポリシー |
| `yafuoku/index.html` | **SAYA 出品ヘルパー**: カメラ在庫をヤフオクに出品するためのタイトル・商品説明の自動生成、在庫リスト、CSV 書き出し。ブラウザだけで動き、データは localStorage に保存 |
| `docs/yafuoku-camera-guide.md` | **ヤフオクでカメラ在庫を高く・楽に売るガイド**: 手数料、開始価格と終了時刻、タイトル・説明文のルール、写真、配送、一括出品ツール、販路の使い分け（出典付き） |

出品ヘルパーはサーバー不要の単一 HTML なので、`yafuoku/index.html` をブラウザで開くだけで使えます。
