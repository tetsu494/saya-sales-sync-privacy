# ヤフオクでカメラ在庫を「高く・楽に」売るガイド

対象: 店舗閉店にともなうカメラ機材（デジタルボディ・レンズ・フィルムカメラ・ストロボ・小物）の在庫処分。
更新日: 2026-10-04。情報源は Yahoo!オークション（旧ヤフオク!）公式ヘルプ・お知らせを中心に、専門店の等級基準、配送会社の公式案内、出品者ブログ（体験談）。各項目の末尾に出典番号を付けています。

> 注意: 調査を行った環境から Yahoo! 公式ヘルプのページ本体を直接開けなかったため、公式の文言は検索結果に引用された内容で確認しています。「要確認」と付けた項目は、出品前に出典 URL を自分で開いて確かめてください。

出品作業そのものは、このリポジトリの `yafuoku/index.html`（SAYA 出品ヘルパー）で型番と状態を入れるだけでタイトル・説明文・写真リストが出ます。本書はその運用ルールです（ツールの開き方とデータの保存先は README を参照）。

## 0. 先に結論

1. **手数料は落札価格の10%で一律**（2024年6月4日以降）。LYPプレミアム（月額508円）に入っても下がらないので、売るためだけに入会する必要はない [1][2][3]。
2. **ストア出品なら7.7%・初期費用月額無料**で、差額は落札総額の2.3%（落札総額500万円で11.5万円）。ただし個人事業主としての出店審査と出店専用IDが要り、ストアにするとYahoo!フリマ同時掲載とまとめて取引は使えない。落札総額が数百万円規模で処分期間に余裕があるときだけ検討する（8章） [4][75][76]。
3. **最低落札価格・太字・背景色・値下げ交渉は廃止済み**。安値落札を防ぐ手段は「開始価格」と「即決のみ（定額）」の2つだけ [5][6]。
4. **人気機種は1円スタート＋日曜21〜23時終了＋自動延長あり**。相場が薄い品や高額単品は**落札相場の7割スタート＋即決併設** [7][8][9]。
5. **タイトルは全角65文字**。「メーカー 型番 別表記 焦点距離/マウント 状態語 付属品 動作一言」の順。出品物と無関係なキーワードは禁止 [10][60][11]。
6. **検索対象はタイトルと説明文の冒頭1000文字**。型番の別表記と付属品は前半に、注意書きは末尾に [12]。
7. **写真は10枚・JPEG・5MB以内・長辺1200px**。出品後は追加のみで差し替え不可。レンズは前玉・後玉を光にかざした写真が必須 [13][14]。
8. **配送は「おてがる配送」で送料込み・匿名**。60サイズ750円・80サイズ850円、補償は30万円まで。30万円超はボディとレンズを別便にするか、ゆうパックのセキュリティサービス（＋420円、50万円）を使う [15][16][17]。
9. **新規アカウントは同時出品100件まで**。本人確認＋評価30件で3,000件に拡張される。最初の100件は売れやすい中価格帯で評価を稼ぐ [18]。
10. **相場が確定している中堅品はヤフオク定額（フリマ同時掲載）で手取りを増やし、残りは買取で下限を押さえる**二段構え。Yahoo!フリマへの直接出品（5%）は、ガイドラインの利用者資格に「事業者ではないこと」とあるため（検索抜粋で確認、原文は要確認）、古物商としての在庫処分では使えない前提で計画する [19][20][21][28]。

### 1-2. アカウントの準備

- **本人確認**を先に済ませる。出品数上限の拡張条件であり、一部カテゴリでは出品の必須条件 [18]。
- **同時出品数は新規100件**。「本人確認済み」「出品時の評価30件以上」「規約違反なし」で3,000件に拡張。解除は問い合わせ申請で、1週間前後 [18][26]。
- **Yahoo!ウォレット**の支払い方法登録（取消料などの請求先）。

### 1-3. 古物商許可と廃業の順序

仕入れた中古品を売るのは古物営業なので、**在庫の売却が終わるまで許可証を返納しない**（売却完了後に廃業届・返納）。新品在庫のみなら許可は不要 [27]。説明文に許可番号を書くと買い手の信頼が上がる（ツールでは「出品の既定値」タブの古物商許可番号に入れると全件の【出品者について】に入る）。ストアで売る場合も出店申込に許可証の情報が要るので、返納は売却完了後という順序は同じ [75]。

要確認 [28][79]:
- 事業者が個人アカウントで売る場合の特定商取引法の表示義務。ヤフオク側のヘルプには「消費税の納税義務者（免税事業者を含む）はストア出品が必要」とする記述があるとされる（検索抜粋、原文未確認）。
- Yahoo!フリマへの直接出品が事業者に認められるか（フリマのガイドラインの利用者資格「事業者ではないこと」の原文と、廃業在庫の処分が事業者出品に当たるか）。
- Yahoo!フリマ同時掲載条件の「出品者が個人であること」が、事業者情報を登録した個人アカウントを含むか。

### 1-4. 相場の調べ方

- **ヤフオク落札相場（無料）**: 検索結果左の「相場を調べる」、または出品フォームの「いくらで売れるか調べる」。URL は `https://auctions.yahoo.co.jp/closedsearch/closedsearch/<キーワード>/0/`。遡れる期間は約120〜180日（要確認） [29]。
- **オークファン**: 無料会員で過去6か月、プレミアム（月額2,200円）で10年分。ライカや希少レンズの年単位の推移を見るなら処分期間だけ契約 [30]。
- **買取価格 = 下限**: マップカメラの「ワンプライス買取」はオンラインで即時表示される。これを下回る落札は意味がないので、開始価格や即決の下限の基準にする [21]。
- ツールの「相場を調べる」リンクは、落札相場・オークファン・中古販売価格を型番から1クリックで開く。買取価格はリンク先の買取ページで型番を入力して確認する。

### 1-5. 2026年のルール改定（出品前にお知らせを確認）

鑑定サービスの有料化（4月〜、主にトレカ・ブランド向け）、転売商材に関する改定（3月19日）、**画像掲載ルールの明確化（8月27日改定）**、SIMカード等の出品禁止（9月28日）。画像ルールは商品写真の載せ方に関わるので、お知らせ本文を確認する [31]。

## 2. 高く売る設定

### 2-1. もう使えない機能

| 機能 | 状態 |
|---|---|
| 最低落札価格、太字、背景色、目立ちアイコン、アフィリエイト | 2019年9月30日終了 [5] |
| 値下げ交渉 | 2021年7月1日終了。代わりに出品中に価格を編集できる [6] |

つまり「安値で落札されるのを防ぐ」には、開始価格を上げるか、定額（開始価格＝即決価格）にするしかない。

### 2-2. 開始価格の3パターン

| 向いている品 | 設定 | 理由 |
|---|---|---|
| 人気機種・相場が明確（現行〜2世代前のボディ、定番レンズ） | **1円スタート**、5〜7日 [35]、日曜夜終了 [33]、即決は相場上限〜1.1倍で併設 [9] | 「安い順」「入札数順」で上位表示されウォッチが集まる。落札額は生の相場になる [7] |
| 高額単品・相場が薄い品（ライカ、希少MFレンズ、中判） | **落札相場の約7割スタート**＋即決併設 | 開始が高すぎると注目されない。7割が入札の集まりやすい線 [8] |
| すぐ現金化したい・相場確定品 | **定額（開始＝即決）**＋自動再出品 [38] | 公式フォームから出せばYahoo!フリマにも自動掲載される（条件は2-6） [19] |

- 即決価格は**現在価格が即決価格に達するまで有効**というのが一般的な理解（公式原文は要確認）。相場より低い即決は競り上がりの余地を自分で消すので置かない。目安は落札相場の上限〜1.1倍（体験談） [9]。
- 1円スタートは「赤字落札」の可能性を受け入れられる品だけ。ニッチ品・高額単品には使わない [7]。

### 2-3. 期間と終了時刻

- 開催期間は**最長7日**。出品フォームでは「終了させたい曜日」と「時間帯（1時間単位）」を選ぶ [32]。
- 終了は**日曜（または土曜）の21〜23時台**が通説。アクセスが多い時間帯という出品者の経験則で、公式統計はない [33]。
- 同じカテゴリの品を同時刻に終わらせると自分の出品同士で入札を奪い合う。**10〜30分ずつずらす**、週を分ける [34]。
- 1円スタートは5〜7日で露出を稼ぐ。定額は短期＋自動再出品で回す [35]。

### 2-4. オプション設定

| 項目 | 推奨 | 備考 |
|---|---|---|
| 自動延長 | **あり** | 終了前5分以内に価格が上がると5分延長。高額品のスナイプ対策 [36] |
| 早期終了 | 非会員は「あり」固定。会員は競り上がりを待つなら「なし」 | [37] |
| 自動再出品 | 定額出品なら2〜3回＋自動値下げ（例 10%） | 回数は0〜3回、カテゴリにより異なる（要確認） [38] |
| 注目のオークション | 高額品のみ、終了前1〜2日に1日20〜50円 | 1出品1日あたり22円（税込）〜、残り日数分が前払い、キャンセル不可 [39] |
| 入札者制限 | 高額品では「悪い評価の割合」制限を検討 | 現行の選択肢と非会員での可否は要確認 [40] |

### 2-5. 送料は「出品者負担（送料込み）」で統一

- 出品者負担だと**全国一律料金**で落札者負担より単価が安い [41]。
- **まとめて取引**（複数落札の同梱）は「出品の商品設定が同じ」ことが条件。送料負担と配送方法を全出品で揃えないと買い手がまとめられない [42]。
- Yahoo!フリマ同時掲載の条件にも「送料出品者負担」が含まれる [19]。
- 送料分は価格に乗せる。数万〜数十万円の品では送料850円より「匿名配送・補償あり」の明記のほうが安心材料になる [43]。

### 2-6. Yahoo!フリマ同時掲載（定額出品のおまけ露出）

個人出品者が以下を満たすと、Yahoo!フリマにも自動で掲載される（止める設定はできない）[19]:
**Yahoo!オークションの出品フォーム（ブラウザ／アプリ）から出品していること**（オークタウン等のAPI経由の外部ツール出品は対象外 [73]）、画像1枚以上、個数1、発送元が日本国内、**送料出品者負担**、**おてがる配送を1つ以上設定**、発送まで7日以内、**定額（開始価格＝即決価格）**、価格300円〜9,999,999円、商品の状態が「全体的に状態が悪い」以外、非対象カテゴリでないこと（カメラ関連が非対象かは未確認）、鑑定未適用、ストア出品でないこと。

フリマ側からの「価格の相談」は使えない。フリマ側で売れた場合の手数料率と取引フローは要確認 [44]。

### 2-7. まとめて取引

同じ出品者から落札し、落札から72時間以内・取引開始前の商品を、依頼商品を含め20件までまとめられる。出品者は承諾時に「別の配送方法を利用する」で合算送料を1つ設定する [42][45]。レンズを複数本買う客が多いカメラでは効くので、送料設定を揃えておく。ストア出品はまとめて取引の対象外（別機能「まとめて購入手続き」になる） [76]。

### 2-8. 未払い・返品の処理（要確認）

数百件を回すと必ず出るのが未払いと返品。以下は公式ヘルプで確認してから高額品を出すこと [46]:
- Yahoo!かんたん決済の支払い期限と、期限超過時の自動キャンセルの有無。
- 「落札者都合での削除」の手順と期限。期限内に削除すれば落札システム利用料は請求されないはずだが未確認。
- 返品時は**落札者が受取連絡を押す前**なら取引ナビからキャンセル・返金できる見込み。説明文に「返品希望は受取連絡を押さずに取引ナビで連絡」と書いておく。

## 3. タイトルの作り方

### 3-1. ルール

- **全角65文字まで**（会員・非会員とも同じ）。半角英数字を0.5文字と数えるかは公式未確認（要確認）。ツールは安全側で1文字＝1と数える [10][60]。
- 検索対象はタイトルと説明文の冒頭1000文字。重要語はタイトルへ [12]。
- **出品物と直接関係のないキーワードは禁止**。「Canon Nikon Sony 対応」のような他社名の羅列や、出品していない機種名の併記はしない。互換性は「○○マウント用」の事実の範囲で [11]。
- 装飾語（★、激安）は検索されないので入れない。
- 「美品」を名乗るなら、マップカメラ基準の「多少の使用感があるものの外観の綺麗な中古品」相当を写真で示せる状態に限る [47]。
- 海外代理購入（Buyee等）の入札を狙う品は、英語表記の正式型番（Nikon F3 HP、CONTAX T2）を入れる [48]。

### 3-2. 語順

```
メーカー 型番（正式名称） 別表記 焦点距離/F値・マウント 状態語 付属品 動作確認・ショット数
```

## 4. 商品説明

### 4-1. ルール

- **タグを使わないプレーンテキスト**で書く。HTMLタグの入力はLYPプレミアム会員限定で、非会員の出品フォームでは使えない（検索抜粋で確認、原文は要確認） [10][74]。会員で使う場合も、タグを1つでも使うと改行に `<BR>` が必要になる。使えるタグは公式ヘルプが別ページ「商品説明でHTMLタグを使う」に案内しているが本調査では未取得で、本書で参照している一覧は二次情報 [49]。タグを使うなら出品プレビューでの表示確認が前提。
- **冒頭1000文字が検索対象**。型番の別表記、マウント、付属品名を前半に。送料・注意事項は末尾 [12]。
- 「ノークレーム・ノーリターン」は一般カテゴリでは禁止されていないが、知っていた不具合を書かなければ免責にならない。「返品送料は落札者負担」などの記載は細則違反の可能性があるので書かない（要確認）[50][51]。
- 「商品の状態」は公式の6段階。ジャンクは「全体的に状態が悪い」[52]:

| 選択肢 | 公式の目安 |
|---|---|
| 未使用 | 未開封、または購入から時間がたっていない一度も使用していない商品 |
| 未使用に近い | 中古ではあるが数回しか使用しておらず、傷や汚れがない |
| 目立った傷や汚れなし | 中古品。よく見ないとわからないレベルの傷や汚れがある |
| やや傷や汚れあり | 中古とわかるレベルの傷や汚れがある |
| 傷や汚れあり | 中古品。ひとめでわかるレベルの大きな傷や汚れがある |
| 全体的に状態が悪い | 中古品。大きな傷や汚れや、使用に支障が出るレベルで不具合がある。ジャンク品など |

- 外観ランクと動作・光学の状態は**分けて書く**（フジヤカメラ方式）。専門店の等級語（新同品／美品／良品／並品／難あり／ジャンク）を使うと専門店で買い慣れた層に伝わる [47][53][54]。

| 当店グレード | 目安（専門店基準の対応） | ヤフオクの「商品の状態」 |
|---|---|---|
| 新同品 | 使用した形跡がほとんどない（キタムラ AA、マップ 新同品） | 未使用に近い |
| 美品 | 使用した形跡が少なく外観が綺麗（キタムラ A、マップ 美品） | 目立った傷や汚れなし |
| 良品 | 小スレはあるが正常動作（キタムラ AB、マップ 良品） | 目立った傷や汚れなし |
| 並品 | 目立つスレ・テカリあり、正常動作（キタムラ B、マップ 並品） | やや傷や汚れあり |
| 難あり | 動作はするがカビ・クモリ等の難点あり（キタムラ C） | 傷や汚れあり |
| ジャンク | 動作不良・部品取り前提（キタムラ D） | 全体的に状態が悪い |

### 4-2. ツールが生成する説明文の構成

```
【商品名】メーカー 型番（別表記）
【マウント】
【コンディション】グレード＋一文の定義
【シャッター回数】約○○回（当店調べ）
【外観】チップで選んだ項目＋補足
【光学】カビ／クモリ／キズ／チリ／バルサム
【動作】確認した項目（未確認項目も書く）
【付属品】付属するもの ／ 欠品
【シリアル】
【備考】
（難あり・ジャンクのときは注意書きが自動で入る）
【出品者について】店舗閉店にともなう在庫処分・古物商許可番号
【発送】おてがる配送（匿名配送）、送料無料、発送元、発送までの日数
【返品】記載と明らかに相違がある場合は到着後3日以内に取引ナビで連絡（受取連絡を押す前に）
定型文（まとめて取引対応、質問は入札前に）
```

【出品者について】以降（店名・許可番号・発送元・配送方法・返品・定型文）は「出品の既定値」タブの内容が全商品共通で入る。商品ごとに書くのは【備考】まで。新品・未使用品では「中古品です」の行と「中古品特有の使用感」の文は自動で外れる。

レンズで必ず書く項目: カビ・クモリ・バルサム切れ・チリ・拭き傷・コーティング、AF/MF・絞り羽根の油染み・ヘリコイドの重さ・手ブレ補正・電子接点、マウント面の摩耗 [55]。
ボディで必ず書く項目: シャッター回数、センサーのゴミ、液晶/EVF、各ボタン・ダイヤル、端子蓋、バッテリーの劣化度、グリップのべたつき [55]。

### 4-3. ジャンクの書き方

「ジャンク」は動作保証なしの現状渡し。**確認できた不具合と未確認の項目を両方書く**。隠した不具合は免責されない [50][56]。例:

```
【ジャンク品について】
・露出計が反応しません（電池新品で確認）。シャッターは全速切れますが精度は未確認です。
・上記以外にも不具合がある可能性があります。部品取り・修理前提で、現状渡し・返品不可です。
```

## 5. 写真

### 5-1. 仕様

1商品10枚まで、1枚5MB以内、JPEG または GIF。長辺1200pxを超えると自動縮小される（要件ではない）。**出品後は画像の削除・差し替えができず、追加のみ**（1枚目のサムネイルは後から変えられない）[13][14]。スマホはJPEG出力に設定し、出品前に全カットのピントを確認する。

### 5-2. 共通ルール

- 最低4面から撮り、10枚を使い切る [57]。
- 自然な色味で。コントラストの強い写真は小傷を隠していると疑われる [58]。
- 説明文に書いた不具合は必ず写真にも写す（写っていないと「見せたくなかった」と判断される）[58]。
- 付属品は全点を1枚に並べる。元箱は型番ラベルが読める向きで [57]。

### 5-3. レンズの10枚プラン

1 前玉を光にかざす（カビ・クモリ確認） 2 後玉を光にかざす 3 正面（フィルター枠・型番刻印） 4 側面（焦点距離・絞り表示・シリアル） 5 マウント面（接点・爪） 6 絞り羽根を絞り込んだ状態 7 鏡筒を伸ばした状態（ズーム）／ヘリコイド 8 フード・キャップ装着 9 傷・不具合箇所のアップ 10 付属品の集合写真（元箱も一緒に）

### 5-4. デジタルボディの10枚プラン

1 正面（レンズなし、ボディキャップ外し） 2 背面（液晶を点灯させる） 3 上面（ダイヤル・シャッター周り） 4 底面（シリアル・三脚穴） 5 側面（端子カバー開・グリップ） 6 マウント内部（センサー／ミラー） 7 ファインダー接眼部 8 シャッター回数の表示画面（通電確認を兼ねる） 9 傷・不具合箇所のアップ 10 付属品の集合写真（元箱は型番ラベルが読める向きで一緒に）

### 5-5. フィルムカメラの10枚プラン

1 正面 2 背面 3 上面（巻き上げ・シャッターダイヤル） 4 底面（シリアル・電池室） 5 裏蓋を開けた内部（圧板・モルト） 6 シャッター幕（レンズを外して） 7 ファインダー接眼部 8 露出計の針／LED表示 9 傷・不具合箇所のアップ 10 付属品の集合写真（元箱・ケースも一緒に）

ストロボ・小物は 全体（正面・背面）／端子・接点・ホットシュー／電池室（液漏れ跡）／発光・動作中／刻印・型番／傷のアップ／付属品集合（元箱も一緒に）の8枚で足りる。

### 6-2. 高額品の補償

- おてがる配送の「お見舞い制度」は実損額の賠償ではなく、**落札価格（＋落札者負担の送料）相当を上限内で見舞う**制度。修理・交換は対象外 [17]。
- 30万円を超える荷物は1個口にしない。ボディとレンズを別便にする。
- 50万円まで補償したいなら**日本郵便のセキュリティサービス（＋420円）**。おてがる配送のメニューにはないので、落札者の住所を聞いて窓口から通常のゆうパックとして出す（匿名配送にはならない）[61]。

### 6-3. カメラ機材特有の注意（要確認）[62]

- **技適マークのない無線ストロボ・ラジオスレーブ**（並行輸入のGodox・Yongnuo等）は規約上の出品禁止物に当たる可能性が高い。国内正規品（技適番号あり）だけ出品する。
- **リチウムイオン電池**は機器に装着した状態で発送し、予備電池単体を小型便（ネコポス・ゆうパケット）で送らない。沖縄・離島向けは陸送扱いで日数がかかることを説明文に注記。
- 発送までの日数の選択肢は「1〜2日」「2〜3日」「3〜7日」。早いほど好まれるが、梱包作業がまとまるなら「2〜3日」が現実的 [63]。

## 7. 出品を楽にする

### 7-1. このリポジトリのツール（yafuoku/index.html）

0. **出品の既定値**タブ: 店名・古物商許可番号・発送元・発送までの日数・配送方法（ゆうパックか宅急便のどちらか一方に統一。6-1）・送料負担（出品者負担。2-5）・返品方針・説明文末尾の定型文を入れて「既定値を保存」。これらは全商品の説明文の【出品者について】【発送】【返品】と末尾定型文に入る。終了曜日/時間と既定の梱包サイズは説明文ではなく、出品カードの「出品フォームで設定する項目」メモと手取り計算に使われる。
1. **まとめて追加**: 在庫表から「種別, メーカー, 型番, グレード, 開始価格, 即決価格, 管理番号」をコピペして一括登録。ツールのCSV書き出し（ヘッダー行付き）もそのまま貼り戻せる。
2. **出品カード**: 検品しながらチップ（外観・光学・動作・付属品）を押すだけで、タイトル（文字数カウント付き）と説明文が生成される。相場リンク、手取りの目安、写真チェックリスト、出品フォームの設定メモ（商品の状態・カテゴリID・終了時刻など）も同じ画面に出る。
3. **在庫リスト**: ステータス（未出品／出品中／落札／発送済）管理。各行の「タイトル＋説明」ボタンで即コピー。
4. **書き出し**: CSV（表計算用）、全件のタイトル＋説明文、JSONバックアップ。データはブラウザ内にだけ保存されるので、定期的にJSONを保存する。

### 7-2. ヤフオク公式の省力化機能

- **同じ商品を出品**: 商品ページ（自分の出品終了分・落札相場・開催中）の「同じ商品を出品する」でカテゴリ・タイトル・説明文を出品画面に引き継ぐ。同型レンズ・同機種の複数台に。会員限定の記述は見当たらないが要確認 [77]。
- **一括再出品**: Yahoo!オークションアプリ限定で、かつLYPプレミアム登録中に出品した商品だけが対象（非会員で出品した分は後から入会しても対象外）。1回50件まで。PCは1件ずつ。非会員運用なら使えないので、まとめて再出品したい場合は 7-3 のオークタウン（再出品4,000件）か自動再出品で代替（検索抜粋で確認、原文は要確認）[64][74][80]。
- **自動再出品＋自動値下げ**: 定額品の放置運用 [38]。
- **下書き**: 10件まで、最後の閲覧から365日。2026年9月から画像は90日で削除（要確認）[65]。
- **定型文**: 発送連絡などの取引メッセージ用。

### 7-3. 外部ツール: オークタウン（CSV一括出品）[66][67]

- Yahoo!オークション公式が紹介する無料の一括出品ツール。Yahoo! JAPAN ID でログインして連携。Excel で編集した CSV をアップロードして一括出品・予約出品（開始日時・終了日時指定）ができる。
- 無料プランは**新規出品200件／再出品4,000件／出品予定リスト400件／画像500枚**。有料は月額2,728円（新規1,000件）と6,028円（新規5,000件）（税込、要確認）。
- CSV の列構成は、登録後に「個別商品登録 → CSV形式でダウンロード」で得られるサンプル CSV と公式「一括出品ガイド」PDF で確認する。カテゴリは**カテゴリID（数値）**で指定、送料負担は「出品者／落札者」、**文字コードは Shift_JIS（Windows-932）**で保存。
- **オークタウン経由の出品はYahoo!フリマに同時掲載されない**（Yahoo!オークションのAPI経由で出品されるため。オークタウン公式FAQ [73]）。フリマ露出を狙う定額品は公式の出品フォームから出し、オークタウンの一括出品はオークション形式（1円／7割スタート）の品と、フリマ露出が不要な定額品に使う。
- ツールの CSV 書き出しはこの列構成に合わせていない（公式仕様を取得できなかったため）。オークタウンを使う場合は、サンプル CSV の列に合わせて表計算ソフトで並べ替える。
- 個人向けの出品 API は2020年1月に終了しており、自作スクリプトでの自動出品はできない [68]。

### 7-5. 大量出品の段取り（実務案）

0. ツールの「出品の既定値」を保存する（配送方法・送料負担はここで全件統一される）。
1. 在庫表をツールに「まとめて追加」し、管理番号を振る。

4. 10枚プランで撮影。レンズは透過写真から。
5. 本人確認を済ませ、最初の100件は売れやすい中価格帯で**評価30件**を稼ぐ。達成後に上限解除を申請。
6. 高額品・希少品は日曜夜終了で、終了時刻を10〜30分ずつずらして小分けに投入。
7. 落札後はおてがる配送の二次元コードで発送（手書き伝票なし）。
8. 残りはまとめて買取へ。
